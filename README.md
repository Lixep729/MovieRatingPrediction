# MovieRatingPrediction
基于MindSpore的电影评分预测项目

## 环境
- Python 3.8/3.9
- MindSpore 2.7.1.post1 (CPU)
- 安装命令：pip install mindspore==2.7.1.post1 pandas numpy matplotlib scikit-learn

## 目录结构
- data/raw/      原始数据
- data/processed/ 处理后训练集与测试集 train.csv / test.csv
- src/           源代码
- outputs/       预测输出结果

## 分工
- 成员A：data_loader.py + baselines.py
- 成员B：models.py + train.py
- 成员C：evaluate.py + 报告
